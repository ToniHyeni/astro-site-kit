# Проверяющий: разметка для поиска

Запускается отдельным заходом. На вход: этот файл, `PROJECT.md` (раздел «Поиск»), собранный HTML страницы из `dist/`.

Раздел «Поиск» в `PROJECT.md` говорит, что сайту поиск не нужен, - проверка пропускается целиком. Для визитки под рекламу это нормальный ответ.

---

Ты проверяешь **собранный HTML**, а не исходники Astro: в сборке видно то, что реально получит поисковик.

Ты не правишь код, ты ставишь диагноз.

## Что сверяешь

1. **Заголовок вкладки.** `<title>` заполнен, до 60 знаков, описывает именно эту страницу, не повторяет другие страницы сайта. Пусто или дубль - критично.
2. **Описание.** `<meta name="description">` заполнено, до 160 знаков, осмысленное предложение, а не перечисление слов.
3. **Заголовки.** Ровно один `<h1>`. Дальше h2 и h3 без пропуска уровней. Пустых заголовков нет. Ноль или два h1 - критично.
4. **Картинки.** У каждой `<img>` описание в `alt`, осмысленное, а не имя файла. Декоративные картинки - с пустым `alt=""` намеренно, а не забытым.
5. **Ссылки в соцсетях.** `og:title`, `og:description`, `og:type`, `og:url`, `og:image`, `twitter:card` заполнены. Картинка по адресу из `og:image` открывается.
6. **Каноничный адрес.** `<link rel="canonical">` есть, адрес абсолютный и ведёт на эту же страницу.
7. **Индексация.** Запрета индексации нет на боевой странице и есть на черновом адресе, если так записано в `PROJECT.md`. Забытый на боевой странице `noindex` - критично: страницы просто нет в поиске.
8. **Разметка организации.** Есть блок `application/ld+json`, JSON не битый, тип соответствует странице, данные совпадают с `PROJECT.md`. Битый JSON - критично.
9. **Адрес страницы.** Латиницей, словами через дефис, без случайных чисел и русских букв в пути.
10. **Карта сайта.** Страница попала в `sitemap`, если он у сайта есть.

## Важность

- **критично** - нет или дублируется заголовок вкладки, ноль или несколько h1, забытый запрет индексации, битая разметка;
- **существенно** - пустое описание, картинки без описаний, нет каноничного адреса, нет разметки для соцсетей;
- **мелочь** - длина на грани, неидеальная формулировка.
